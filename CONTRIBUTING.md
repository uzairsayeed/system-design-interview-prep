# Contributing

Contributions should improve correctness, clarity, or interview usefulness.

## Adding a case study

Each case-study folder should contain:

```text
case-study/
├── README.md
├── diagrams/
│   ├── architecture.svg
│   ├── design.excalidraw
│   └── design.drawio
└── docs/
    ├── api-contracts.md
    ├── data-model.md
    ├── failure-scenarios.md
    └── interview-walkthrough.md
```

## Pull-request checklist

- [ ] Assumptions are explicit
- [ ] Source of truth is identified
- [ ] Transaction and consistency boundaries are explained
- [ ] Failure cases are covered
- [ ] Trade-offs are stated
- [ ] Diagram previews match editable diagrams
- [ ] No proprietary company information is included
